# Tuinve SD — Canal de actualizaciones

Este repositorio aloja **únicamente los instaladores** de Tuinve SD.
No contiene código fuente.

La aplicación lo consulta automáticamente para detectar versiones nuevas.
No hace falta descargar nada manualmente desde aquí: si tienes Tuinve SD
instalado, te avisa solo cuando hay una actualización disponible.
